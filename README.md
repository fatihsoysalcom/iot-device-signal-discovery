# IoT Device Signal Discovery

This Python example simulates a real-time IoT environment where devices broadcast signals (heartbeats). Other devices listen for these signals to discover and track the presence of other devices, demonstrating a signal-driven approach to room discovery and re-connection proof.

## Language

`python`

## How to Run

Run this script using Python: `python iot_discovery.py`
